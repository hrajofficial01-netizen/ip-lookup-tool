About IP & URL Lookup Tool

🚀 Welcome to the IP & URL Lookup Tool

Your one-stop utility for analyzing and investigating suspicious IP addresses and URLs — fast, reliable, and intelligently designed for security teams.

🔍 Core Features

  • Dual Input Support: Accepts both IP addresses and URLs.
  • IP Intelligence: Get ISP, country, and detection count.
  • URL Scanning: Integrated with VirusTotal API for malicious detection.
  • Strict Validation: Filters duplicates, private, and invalid entries. Handles 100 entries in under 5 seconds.
  • Summaries: Displays lookup and API usage separately.
  • Detailed Table Output: Includes ISP, geolocation, and detections.
  • Copy & Download: Clipboard and Excel export functionality.
  • Theming: Smooth toggle between dark and light modes.
  • Modern UI: Neon borders, transitions, responsive layout.

🎯 Ideal For

  • Cybersecurity researchers
  • Threat investigators & analysts
  • Network admins & developers
  • Anyone validating suspicious IPs or links
  • Especially dedicated to the SOC teams with an attempt to facilitate their daily tasks.
